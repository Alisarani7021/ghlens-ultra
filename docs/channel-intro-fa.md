# معرفی ربات برای کانال — نسخهٔ Rich

این متن یک‌بار (۲ مهر ۱۴۰۵ / 2026-09-24) برای مالک ارسال شد (message_id `635`، ۱۲ بلوک).
اینجا نگه داشته می‌شود تا هر وقت خواستی دوباره بفرستی یا ویرایشش کنی.

**چرا Rich:** کانال‌های فنی با متنِ ساده خوانده نمی‌شوند. جدولِ حاشیه‌دار، بخش‌های
بازشو و فوتر باعث می‌شود پست در یک نگاه اسکن شود و کسی که فقط ۵ ثانیه وقت دارد هم
بفهمد این ربات چه کار می‌کند؛ دکمه‌های داخل پیام هم همان‌جا او را به ربات می‌برند.

## ارسال

```bash
set -a && source .secrets.local.sh && set +a
python3 - <<'EOF'
import json
html = open("docs/channel-intro-fa.rich.html").read()
json.dump({"chat_id": <CHAT_ID>, "rich_message": {"html": html, "is_rtl": True}},
          open("/tmp/post.json", "w"), ensure_ascii=False)
EOF
curl -s -X POST "https://api.telegram.org/bot$BOT_TOKEN/sendRichMessage" \
  -H 'content-type: application/json' --data-binary @/tmp/post.json
```

برای گذاشتن در کانال: پیام را برای کانال فوروارد کن، یا همین HTML را با `chat_id`
کانال بفرست. `is_rtl: true` لازم است وگرنه متن فارسی چپ‌به‌راست چیده می‌شود.

## منبع Rich

فایل کنارِ همین سند: `docs/channel-intro-fa.rich.html`
