# معرفی ربات برای کانال — نسخهٔ Rich

دو نسخه در این پوشه است؛ نسخهٔ دوم (فعلی) با تصویر برند و متنِ مهندسی‌تر برای کانال:

| نسخه | فایل Rich | فرستاده شد |
|---|---|---|
| v1 — معرفی محصول، بنر انتزاعی | ~~channel-intro-fa.rich.html~~ | message_id 635 |
| v2 — متن مهندسی + تصویر برند | `channel-intro-fa.rich.html` (فعلی) | در دایرکت مالک |

**چرا Rich:** کانال‌های فنی با متنِ خالی خوانده نمی‌شوند. تصویر، جدولِ حاشیه‌دار،
بخش‌های بازشو و دکمهٔ درون‌پیام باعث می‌شود پست در یک نگاه اسکن شود و کسی که ۵ ثانیه
وقت دارد هم بفهمد ربات چه می‌کند و کجا برود.

## ارسال

```bash
set -a && source .secrets.local.sh && set +a
python3 - <<'EOF'
import json
html = open("docs/channel-intro-fa.rich.html").read()
json.dump({"chat_id": <CHAT_ID>, "rich_message": {"html": html, "is_rtl": True}},
          open("/tmp/post.json", "w"), ensure_ascii=False)
EOF
curl -s -X POST "https://api.telegram.org/bot$BOT_TOKEN/sendRichMessage" \
  -H 'content-type: application/json' --data-binary @/tmp/post.json
```

برای کانال: پیام را فوروارد کن، یا همین HTML را با `chat_id` کانال بفرست.
`is_rtl: true` لازم است وگرنه متن فارسی چپ‌به‌راست چیده می‌شود. تصویر داخل پست با
`<tg-collage>` از `docs/assets/hero.jpg` روی CDN خامِ گیت‌هاب خوانده می‌شود — پس تا
فایل پوش نشده باشد، تلگرام `RICH_MESSAGE_PHOTO_NO_MEDIA_FOUND` می‌دهد.
