🔭 GitHub Lens Ultra

هر مخزنی، هر نسخه‌ای، هر آسیب‌پذیری — از پشت یک لنز. گیت‌هاب را می‌آورد داخل تلگرام؛ همان‌جایی که هستی.@Gitguts_bot

یک ربات تلگرامی که کارِ گیت‌هاب را در همان چت تمام می‌کند: نه مرورگر لازم است، نه حساب تازه. یک موضوع بنویس یا یک owner/repo بفرست — بقیه‌اش با ربات.

⚡ در یک نگاه
بخشچه می‌کند
🔍 جست‌وجوی معناییلازم نیست اسم دقیق پروژه را بدانی: «یک کتابخانهٔ سبک برای صف در Go» را می‌فهمد
🛰 پروندهٔ مخزن — ۱۲ تبرشد، ضریب اتوبوس، نرخ مرج، ریلیز، مشارکت‌کننده، CI، وابستگی، امنیت، چنج‌لاگ، نقشهٔ کد — با عدد واقعی از API گیت‌هاب
🧠 هوش مصنوعی۱۱ مدل در ۳ رده + ردهٔ چندمدلی (موازی → داور → سنتز)؛ چت با مخزن با استناد، ترجمهٔ README، بازبینی PR، توضیح کد
📥 دانلود سورسزیپ یا تار، کِش‌شده، و برای مخزن‌های بزرگ خودکار تکه‌تکه — با اسکن امنیتی پیش از تحویل
🛡 امنیتاسکن وابستگی با OSV، شکار کلید لو‌رفته، هشدار CVE
🧰 جعبه‌ابزارIP/DNS/ASN/TLS، JWT، هش، کرون، CIDR، رجکس، SemVer و ۱۵ ابزار دیگر — همه در چت
🌌 هاب جهانیرویداد می‌گیرد (ریلیز، فید، تغییر API)، ورک‌فلو اجرا می‌کند، پست را پیش‌نویس می‌کند — و بی‌رضایت تو چیزی منتشر نمی‌شود
🌐 پنج زبانفارسی · انگلیسی · عربی · روسی · چینی — رابط و پیام‌ها، نه تزئینی
🎯 از کجا شروع کن؟
  • یک موضوع بنویس — مثل «کتابخانهٔ سبک برای صف در Go» — و فهرست کوتاه‌شده‌ای با ستاره، آخرین ریلیز و وضعیت امنیت بگیر
  • owner/repo بفرست — پروندهٔ کامل مخزن، همان لحظه
  • /dl owner/repo سورس را می‌دهد، /scan owner/repo امنیتش را می‌سنجد
  • /help — همهٔ ۹۳ فرمان، دسته‌بندی‌شده
🤖 هوش مصنوعی، بدون توهم
  • چت با مخزن، با استناد به فایل و خط — نه جواب سربالا
  • ترجمهٔ README با حفظ ساختار، جدول و کد — صفحه‌به‌صفحه تا آخر
  • برای سؤال‌های مهم، چند مدل هم‌زمان جواب می‌دهند و یک داور جمع‌بندی می‌کند
  • کلید هوش مصنوعی خودت را وصل می‌کنی؛ کلیدهای اهدایی در استخری مشترک استفاده می‌شوند و کلید مرده خودکار کنار می‌رود
🔐 حساب، داده، کلید
  • وصل‌کردن گیت‌هاب با کم‌ترین دسترسی لازم؛ رمزنگاری‌شده و با یک دکمه پاک‌شدنی
  • هیچ پروفایلی از تو ساخته نمی‌شود و هیچ داده‌ای جای دیگری نمی‌رود
🧱 زیر کاپوت، و مرزها

تمامش روی لبهٔ Cloudflare: Workers، D1، KV، Queues، Durable Objects، Workers AI. همهٔ عددها از API واقعی گیت‌هاب و OSV می‌آید؛ هوش مصنوعی فقط خلاصه و توضیح می‌دهد — عدد نمی‌سازد.

مرزها را هم می‌گوید: تصاویر فقط فهرست می‌شوند، PDF اسکن‌شده OCR نمی‌شود، و سقف آپلود تلگرام ۴۹ مگابایت است — برای همین فایل‌های بزرگ خودکار تکه‌تکه می‌شوند.
