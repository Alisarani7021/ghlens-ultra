## عوض‌کردن عکس پروفایل

عکس پروفایل ربات را **API تلگرام نمی‌گذارد خودِ ربات عوض کند**؛ فقط از BotFather:

```
@BotFather → /setuserpic → انتخاب @Gitguts_bot → فایل تصویر را بفرست
```

`docs/assets/avatar.png` آواتاری است که از این چهار گزینه انتخاب شده و همین حالا در مخزن به‌عنوان چهرهٔ رسمی پروژه استفاده می‌شود.

## اگر آواتار عوض شد

تصویر انتخاب‌شده را روی `docs/assets/avatar.png` کپی کن (README بالای صفحه از همان استفاده می‌کند) و اگر خواستی بنر استارت هم همراه شود، `docs/assets/start-banner*.png` را از همان پالت رنگ بازتولید کن.
