# راهنمای استفاده — هاب جهانی GHLens Ultra

> هر قابلیت با سه چیز نوشته شده: **از کجا باز می‌شود**، **آنجا چه کار می‌کنی**، و **جوابی که می‌گیری**.
> مدل ذهنی کل سیستم در یک خط: **اتفاق بیرون → رویداد → ورک‌فلو → محتوا → تأیید تو → انتشار**.

---

## ۰) از کجا وارد شوم؟

`⚙️ تنظیمات` → «🌌 **هاب جهانی** — اتوماسیون و رویدادها»

صفحهٔ خانه وضعیت زنده را می‌گوید (چند کانکتور فعال، چند ورک‌فلو، چند مورد منتظر تأیید تو) و همهٔ بخش‌ها را
به‌صورت دکمه دارد. با دکمهٔ «📖 راهنما: از کجا چه کاری» همین متن به‌صورت خلاصه داخل ربات هم هست.

**قاعدهٔ مهم:** هر بخش یک «حالت ورودی» دارد. اگر در «مأموریت» هستی و متن بفرستی، همان‌جا مصرف می‌شود؛
اگر دکمهٔ بخش دیگری را بزنی، از حالت قبلی بیرون می‌آیی. حالت بعد از ۲۵ دقیقه بی‌کاری خودش پاک می‌شود.

---

| 📚 **برنامه‌های آماده** | دکمه در خانه | یک لمس برای نصب | ورک‌فلوی آمادهٔ تست‌شده |

| 🖼 **کارخانهٔ رسانه** | دکمه در خانه | یک موضوع بنویس | کاور SVG + پرامپت تصویر + متن جانشین |

## ۲) یک سناریوی کامل، از صفر تا پست در کانال

۱. `🔌 کانکتورها` → «افزودن» → **تلگرام** → کانفیگ: `channel: "@my_channel"` → «تست»
   → باید بگوید «دسترسی تأیید شد — نام کانال».
۲. `🔌 کانکتورها` → «افزودن» → **گیت‌هاب** → کانفیگ: `repos: ["oven-sh/bun"]` → «تست» (سهمیهٔ API را می‌گوید).
۳. `📚 برنامه‌های آماده` → «🚀 انتشار نسخهٔ جدید در کانال» → نصب.
   از این لحظه هر نسخهٔ جدیدی از آن مخزن‌ها به رویداد تبدیل می‌شود.
۴. برای امتحان بدون انتظار: `🎯 رویدادها` → «🧪 رویداد آزمایشی».
۵. `🕹 صف تأیید` → پیش‌نویس را باز کن:
   - **✅ تأیید و انتشار** → پست در کانال می‌رود؛ سرِ پست لینک پروژه است و برای **هر فایل** یک دکمهٔ دانلود
     (با حجم و تعداد دانلود). دقیقاً یک‌بار منتشر می‌شود.
   - **✏️ ویرایش متن** → متن تازه را بفرست؛ جایگزین می‌شود (نسخه +۱) و کارت تأیید برمی‌گردد.
   - **🗑 رد** → محتوا مسدود می‌شود و اجرای معلق هم بسته می‌شود.
۶. `📊 اجراها` → ببین هر گره چه کرد؛ `🕸 گراف محتوا` → نسب و DNA همان پست.

## ۳) کالبدشکافی فایل

- از بخش «📄 کالبدشکافی فایل» (یا هر بخش هاب) فایل را بفرست. پشتیبانی: `txt · md · csv · json · xml · yaml ·
  html · PDF متنی · همهٔ زبان‌های کد`.
- خروجی: نوع تشخیص‌داده‌شده، حجم، برای PDF تعداد صفحات، فکت‌های ساختاری (تعداد سرتیتر/لینک/بلوک کد، ستون‌های CSV…)،
  موجودیت‌ها، و **برداری‌سازی برای جست‌وجو**.
- PDF اسکن‌شده: صادقانه می‌گوید «متن پیدا نشد — احتمالاً اسکن‌شده است (بدون OCR خوانده نمی‌شود)».
- **صوت و ویدیو پذیرفته نمی‌شود** (طبق درخواست خودت، هیچ مسیر صوتی در ربات نیست).
- از بیرون (CI، اسکریپت، اپ دیگر) با HTTP:

```bash
curl -X POST "https://ghlens-ultra.gitguts.workers.dev/hub/ingest?name=build.log&uid=<telegram-id>&key=<PLATFORM_KEY>" \
     -H 'content-type: text/plain' --data-binary @build.log
# &embed=0 → بدون برداری‌سازی (سریع‌تر)
# سقف ۲۰ مگابایت، بدنهٔ خام فایل
```

## ۴) دانش و جست‌وجوی معنایی

- `🧠 دانش و جست‌وجو` → موجودیت‌های پرتکرار + «اسناد: N · برداری‌شده: M».
- «🔎 جست‌وجوی معنایی» → یک **جملهٔ معمولی** بنویس؛ لازم نیست کلمهٔ مشترکی با متن داشته باشد
  (مثال واقعی: «نسخه جدید رانتایم جاوااسکریپت» → «Bun v1.2.0» با ۵۵٪).
- کنار هر نتیجه راهِ پیداشدن گفته می‌شود: **موجودیت** / **برداری (معنایی)** / **واژه‌ای** — یعنی هیچ‌وقت
  پنهانی حدس نمی‌زند.
- بردارها در D1 ذخیره می‌شوند (`dim=1024`)، پس بدون Vectorize هم کار می‌کند.

## ۵) کارخانهٔ رسانه

- `🖼 کارخانهٔ رسانه` → موضوع را بنویس → سه چیز می‌گیری:
  ۱) **کاور ۱۲۰۰×۶۹۰** به‌صورت فایل SVG (رنگ تأکیدی از هش عنوان ساخته می‌شود، پس هر موضوع کاور خودش را دارد)،
  ۲) **پرامپت تصویر انگلیسی** به‌شکل JSON (سبک، نسبت تصویر، نگاتیو) برای هر مدل تصویری،
  ۳) **متن جانشین فارسی (alt)** برای دسترس‌پذیری.
- هیچ خروجی صوتی ندارد.

## ۶) وب‌هوک (ورودی رویداد از سرویس‌های بیرونی)

`🔌 وبهوک و گیت‌وی` آدرس دقیق هر کانکتور را می‌دهد: `POST /hooks/<source>/<hook_key>`.

| سرویس | اعتبارسنجی | نکته |
|---|---|---|
| GitHub | `x-hub-signature-256: sha256=<HMAC-SHA256(secret, raw body)>` | نوع رویداد در `x-github-event` |
| Stripe | `t=…,v1=…` | پنجرهٔ ۳۰۰ ثانیه‌ای برای جلوگیری از بازپخش |

- امضای غلط → **۴۰۱** و بدنه حتی پردازش نمی‌شود.
- ارسال تکراری (GitHub دوباره می‌فرستد) → `duplicate: true, runs: []` — برنامه دوباره اجرا نمی‌شود.
- رویداد از مخزنی که در کانکتور نیست → `ignored: "repo not watched"`.

## ۷) دروازهٔ AI (سازگار با OpenAI)

هر اپ یا اسکریپتی که OpenAI را صدا می‌زند، فقط `base_url` را عوض کند:

```bash
curl https://ghlens-ultra.gitguts.workers.dev/v1/chat/completions \
  -H "authorization: Bearer <PLATFORM_KEY>" -H 'content-type: application/json' \
  -d '{"model":"ghlens-auto","messages":[{"role":"user","content":"سلام"}]}'
```

- `GET /v1/models` باز است و ۵ شناسه می‌دهد: `ghlens-auto · ghlens-fast · ghlens-smart · ghlens-code · ghlens-mesh`.
- `ghlens-auto` خودش کار را تشخیص می‌دهد (`compose · extract · code · translate · analyze`) و مدل را می‌چیند.
- `ghlens-mesh` چند مدل را موازی می‌گیرد، داور می‌کند و اگر توافق بالا باشد سنتز می‌کند؛ درجهٔ توافق در پاسخ می‌آید.
- پاسخ اضافه‌ای به استاندارد دارد: فیلد `ghlens` = `{chosen, models, agreement, task, confidence}`.
- `"stream": true` → SSE با `chat.completion.chunk` و پایان `[DONE]`.
- کلید نامعتبر/غایب → **۴۰۱** `invalid api key`. هر فراخوانی در `hub_gateway_log` ثبت می‌شود (آمار ۷ روز در همان صفحه).

## ۸) دیپلوی یک‌کلیکی

`🚀 ساخت نمونهٔ شخصی` → «🔑 ساخت توکن با همین دسترسی‌ها» (داشبورد با هفت تیک باز می‌شود) →
توکن کلاودفلر را بفرست (خط دوم، اختیاری: توکن ربات خودت) →

```
✅ تأیید توکن → ✅ انتخاب حساب → ✅ گرفتن باندل نسخهٔ فعلی
→ ✅ ساخت/بازاستفادهٔ D1 و دو KV و صف → ✅ اجرای ۷۵ دستور اسکیما
→ ✅ آپلود ربات → ✅ آدرس workers.dev → ✅ کرون + مصرف‌کنندهٔ صف + وبهوک تلگرام
→ ✅ تست واقعی: /v1/models نسخهٔ جدید باید ۲۰۰ بدهد
```

نکته‌ها: اگر منابع هم‌نام باشند دوباره ساخته نمی‌شوند (اجرای دوباره بی‌خطر است). کپی تازه ۴۰ تا ۶۰ ثانیه
طول می‌کشد تا از لبه سرو شود؛ اگر تا آن موقع جواب نده، گزارش می‌گوید «لبه هنوز منتشر نشده»، نه «خراب شد».
سقف ۵ کرون در پلن رایگان ممکن است باعث شود زمان‌بندی نسخهٔ کپی ثبت نشود (صریح ⚠️ گفته می‌شود).

## ۹) خودکار، بدون تو

| زمان | چه کار |
|---|---|
| هر ۱۵ دقیقه | چک‌کردن کانکتورها و تبدیل اقلام تازه به رویداد + کارهای صف |
| ساعتی | ایندکس و کارهای امنیتی |
| روزانه ۰۶:۰۰ UTC | نگهداری روزانه (+ هفتگی یک‌شنبه‌ها، ماهانه اول ماه) |

## ۱۰) وقتی چیزی کار نکرد

- **دکمه هیچ واکنشی نشان نداد؟** یعنی آن بخش دیگر معتبر نیست؛ از خانه دوباره وارد شو.
- **پیام متنی‌ام به بخش اشتباه رفت؟** حالت قدیمی پاک نشده بود؛ هر بخش ۲۵ دقیقه پس از بی‌کاری خودش پاک می‌شود و
  با زدن دکمهٔ بخش دیگر هم پاک می‌شود.
- **صف خالی است ولی چیزی منتشر نشد؟** سراغ `📊 اجراها` برو: آنجا می‌بینی کدام گره کجا ایستاد و چرا.
- **کانکتور تستش قرمز است؟** صفحهٔ تست دقیقاً علت را می‌گوید (توکن، نبود دسترسی ادمین در کانال، سهمیهٔ API).
- **ربات در کانال پست نگذاشت؟** «دروازهٔ سیاست» ممکن است جلویش را گرفته باشد؛ در `📊 اجراها` خلاصهٔ دروازه نوشته می‌شود.

## ۱۱) محدودیت‌های صادقانه

- `POST /v1/embeddings` وجود ندارد (برداری‌سازی داخلی هست، مسیر OpenAI آن نه).
- OCR برای PDF اسکن‌شده نداریم و ادعایش هم نمی‌کنیم.
- صوت/ویدیو/گویندگی به‌عمد حذف شده و برنمی‌گردد.
- آپلود تلگرام سقف ۲۰ مگابایت دارد (برای فایل‌های بزرگ‌تر از `/hub/ingest` استفاده کن).
- لینک پروژه به‌صورت لینکِ سرِ پست است (روی نام مخزن)، کنارِ یک دکمهٔ دانلود برای هر فایل؛ اگر دکمهٔ جدا هم
  لازم داشتی، بگو تا اضافه شود.
